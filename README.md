# Healthcare Claims Data Analysis using Microsoft Excel

## 📌 Project Overview

This project analyzes a healthcare claims dataset using Microsoft Excel. The objective was to clean the data, perform business analysis using Pivot Tables, create Pivot Charts, and build an interactive dashboard.

## 📊 Dataset

- Total Records: 250
- Industry: Healthcare
- File Format: Microsoft Excel (.xlsx)

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard
- Data Cleaning

## 📈 Business Questions Answered

- Claim Status Distribution
- Total Claim Amount by Insurance Provider
- Number of Claims by Insurance Provider
- Average Days to Process by Insurance Provider
- Total Paid Amount by Diagnosis
- Average Patient Age by State

## 📌 Dashboard KPIs

- Total Claims: 250
- Total Claim Amount: ₹69,37,753
- Average Paid Amount: ₹17,789
- Denied Claims: 29
